
### Documentation Overview
*   **Regex-based Parsing**: The tool uses regular expressions to identify log levels like `INFO`, `WARNING`, and `ERROR` regardless of the surrounding text[cite: 3].
*   **Error Counting**: It automatically tallies the occurrences of each severity level to give you a high-level view of server health[cite: 2].
*   **Insight Extraction**: Beyond simple counting, it extracts the specific text of error messages and identifies the top recurring issues to help with troubleshooting[cite: 2].
*   **No External Dependencies**: The script is designed to run on any standard Python 3.x installation without needing extra packages like `pandas` or `numpy`[cite: 2].
